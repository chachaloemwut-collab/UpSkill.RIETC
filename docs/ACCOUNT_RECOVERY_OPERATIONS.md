# งานทะเบียนและการกู้บัญชี UpskillReskill.RIETC

ผู้เรียนเปิดลืมรหัสผ่านเพื่อรับลิงก์ทางอีเมลเดิม หรือเปิด /recovery เพื่อแจ้งงานทะเบียนโดยไม่ต้องเข้าสู่ระบบ ผู้เรียนเก็บเลขเรื่องและรหัสติดตามไว้ทั้งคู่ เบอร์โทรศัพท์หรืออีเมลที่แจ้งเป็นช่องทางนัดตรวจตัวตน

## มอบหมายและตรวจเรื่อง

1. เจ้าของระบบเข้า จัดการสมาชิก → จัดการเรื่องขอกู้บัญชี → มอบหมายหน้าที่ เลือกรหัสบัญชีผู้ดูแลซึ่งแสดงในหน้ารายละเอียดสมาชิก มอบหน้าที่ตรวจทะเบียนและอนุมัติให้คนละคน ผู้ตรวจสอบใช้ดูประวัติงาน
2. เจ้าหน้าที่ค้นด้วยเลขเรื่องและรับดำเนินการ ตรวจบัญชีเดิมจากหน้าจัดการสมาชิก หากเมลไม่ถึง ตรวจคิวส่งเมลและสถานะผู้ส่งในหน้าอีเมลของผู้ดูแลก่อนส่งซ้ำ
3. ทะเบียนตรวจเจ้าของกับข้อมูลทะเบียนหรือพบตัวตามวิธีของวิทยาลัย กรณีผู้เยาว์ตรวจสิทธิ์ผู้ปกครองตามขั้นตอนที่วิทยาลัยรับรอง เก็บหลักฐานในช่องทางทะเบียนที่ได้รับอนุญาต ในระบบกู้บัญชีบันทึกเฉพาะวิธีตรวจ บัญชีเป้าหมาย ผู้ดำเนินการและเวลา
4. หากพบบัญชีซ้ำ ให้ระบุทั้งสองบัญชีแล้วตรวจยอดลงทะเบียน รอบอบรม ความก้าวหน้า ผลสอบ และวุฒิบัตรก่อนเลือกบัญชีเดิม การออกสิทธิ์กู้มีผลเฉพาะบัญชีที่เลือก การย้ายประวัติรายบุคคลต้องได้รับการพิจารณาจากเจ้าของข้อมูลและทะเบียน
5. ผู้อนุมัติเปิดประวัติและบัญชีเป้าหมายก่อนอนุมัติ ผู้อนุมัติต้องเป็นคนละคนกับผู้รับเรื่องและผู้ตรวจทะเบียน ทะเบียนผู้ตรวจเดิมออกลิงก์และส่งมอบเป็นการส่วนตัวตามวิธีตรวจที่บันทึก ลิงก์ใช้ได้ครั้งเดียวภายใน 30 นาที หากต้องยกเลิก ให้ผู้รับเรื่องกดยกเลิกก่อนลิงก์ถูกใช้
6. ผู้เรียนตั้งรหัสผ่านและเข้าสู่บัญชีเดิม การตั้งรหัสสำเร็จกับการกลับเข้าเรียนเป็นคนละเหตุการณ์ เจ้าหน้าที่ตรวจได้จากประวัติในเรื่อง ผู้เรียนเพิ่มและยืนยันอีเมลใหม่ได้จากหน้าบัญชี แล้วตั้งเป็นอีเมลหลัก

## การเปิดใช้งานและพักการออกสิทธิ์

เปิดรับเรื่องและติดตามได้โดยไม่ต้องตั้ง SMTP การส่งอีเมลจริงยังขึ้นกับผู้ส่ง คิว และ DNS ของโฮสติ้ง ขั้นตอนออกลิงก์ผ่านทะเบียนต้องมีเจ้าหน้าที่ที่ได้รับมอบหมายและผู้อนุมัติ ก่อนเริ่มใช้กับผู้เรียนจริง ให้งานทะเบียนกำหนดผู้รับผิดชอบ วิธีส่งมอบ ช่องทางผู้เยาว์ และระยะเก็บข้อมูลติดต่อ

เมื่อทะเบียนมอบหมายเจ้าหน้าที่พร้อมแล้ว ตั้ง RECOVERY_CASE_ONLY=on เพื่อให้การส่งมอบสิทธิ์ด้วยมือทุกบัญชีผ่านการตรวจสองคน ระหว่างเตรียมเจ้าหน้าที่ บัญชีที่ไม่มีอีเมลยืนยัน บัญชีที่เคยผ่านทะเบียน และบัญชีเป้าหมายที่รออนุมัติต้องผ่านคิวทะเบียนเสมอ

ผู้ดูแล deployment สามารถตั้ง RECOVERY_CASE_ISSUANCE=off เพื่อพักการออกลิงก์ใหม่ และ RECOVERY_CASE_INTAKE=off เพื่อพักการรับเรื่องใหม่โดยยังติดตามเรื่องเดิมได้ การพักการออกลิงก์ยังคงอายุเดิมของสิทธิ์ที่ส่งมอบแล้ว ผู้รับเรื่องสามารถยกเลิกเป็นรายเรื่อง ฐานข้อมูลรองรับแอปรุ่นก่อนผ่านคอลัมน์ใหม่แบบ nullable พร้อมเก็บผู้รับของลิงก์ที่ยังใช้ได้จากคิวอีเมล

ตั้ง RECOVERY_CONTACT_RETENTION_DAYS ใน worker ตามระยะที่วิทยาลัยอนุมัติ (1 ถึง 3650 วัน) เมื่อครบกำหนดระบบล้างช่องทางติดต่อของเรื่องที่ปิด ยุติ หรือยกเลิก และเก็บประวัติการดำเนินการไว้ตรวจสอบ หากยังไม่ได้กำหนด ช่วงเก็บข้อมูลต้องให้งานทะเบียนพิจารณาก่อนเปิดใช้งาน

หลังปล่อย ให้ตรวจสถานะ receiver และ commit ของ Jasmine ตรวจ /api/health, /login, /forgot-password และ /recovery แล้วทดสอบส่งถึงกล่องที่วิทยาลัยควบคุม เก็บผลการส่งและเข้าเรียนโดยปิดบังข้อมูลผู้เรียน รายงานปัญหา DNS ของโฮสติ้งติดตามที่ Issue #81
