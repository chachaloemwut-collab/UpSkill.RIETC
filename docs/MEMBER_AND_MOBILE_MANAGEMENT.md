# บัญชีสมาชิกและหน้าจอแอปของ UpskillReskill.RIETC

| งานเดิม | จุดที่ทำให้ใช้งานยาก | การปรับในรุ่นนี้ |
| --- | --- | --- |
| ดูแลข้อมูลสมาชิก | การแก้เบอร์โทรหรือที่อยู่ต้องผ่านฟอร์มข้อมูลส่วนตัวหลายรายการ | สมาชิกเปิดหน้าบัญชี เลือกข้อมูลส่วนตัว แล้วแก้เฉพาะข้อมูลติดต่อ ระบบส่งเฉพาะค่าที่เปลี่ยน |
| ดูแลการเข้าสู่ระบบ | การยกเลิกทุกอุปกรณ์กระทบผู้เรียนที่ใช้งานอยู่ | สมาชิกดูรายการอุปกรณ์ที่ยังเข้าใช้ได้ เห็นเวลาล่าสุดและเครื่องปัจจุบัน เลือกยกเลิกทีละรายการและยืนยันก่อนดำเนินการ |
| จัดการสมาชิกโดยผู้ดูแล | ตารางอ่านยากบนมือถือ เวลาล่าสุดอิงตอนเริ่มใช้งาน | หน้ารายชื่อแสดงเป็นรายการบนมือถือ ใช้เวลาใช้งานล่าสุดจากระบบ รายละเอียดแยกการเข้าสู่ระบบที่หมดอายุ ผู้ดูแลยกเลิกอุปกรณ์ของสมาชิกรายที่เลือกได้ |
| การลบบัญชี | เจ้าของระบบเข้าถึงปุ่มลบตนเอง | ตรวจทั้งหน้าจอและบริการลบบัญชี เจ้าของระบบยังดาวน์โหลดข้อมูลตนเองได้ |
| จัดการรุ่นอบรมและใบสมัคร | รุ่นร่างที่ไม่ใช้ค้างอยู่ และเปลี่ยนลำดับคำถามได้ยาก | ลบรุ่นร่างที่ไม่มีข้อมูลอ้างอิงได้หลังยืนยัน จัดลำดับคำถามและตรวจเงื่อนไขก่อนบันทึก ตรวจการแก้ไขชนกันในหน้ารุ่นอบรม |
| เข้าใช้งานจากโทรศัพท์หรือไอคอนแอป | ผู้เข้าชมเริ่มจากหน้าแนะนำ และหน้าบัญชีรวมหลายฟอร์มไว้ในหน้าเดียว | หน้าเริ่มต้นแสดงงานที่ใช้บ่อยตามสถานะผู้ใช้ หน้าบัญชีแยกเป็นรายการและหน้ารายละเอียด ย้อนกลับได้ทั้งจากตัวแอปและเบราว์เซอร์ |

## แนวทางดูแลหลังส่งมอบ

การสมัครสมาชิก ยืนยันอีเมล ตั้งรหัสผ่าน จัดการบทบาทและสถานะบัญชี ใช้กระบวนการเดิมของระบบ การแยกหน้ามือถือใช้บริการข้อมูลและตรวจสิทธิ์ชุดเดียวกับเว็บ เมื่อกดหยุดการใช้งานอุปกรณ์ ระบบบันทึกผู้ดำเนินการและรายการที่ถูกยกเลิกในประวัติการตรวจสอบ

แอปที่ติดตั้งเปิดจากไอคอนด้วยโหมด standalone มือถือที่เข้าจากเบราว์เซอร์ใช้หน้าเริ่มต้นสำหรับงานประจำได้เช่นกัน ผู้เยี่ยมชมเลือกดูเว็บไซต์เต็มได้ การบันทึกข้อมูลและจัดการอุปกรณ์ต้องเชื่อมต่อกับระบบเพื่อยืนยันสิทธิ์และอ่านผลล่าสุด

## จุดตรวจรับ

- ใช้บัญชีทดสอบสองเครื่อง ยกเลิกเครื่องหนึ่ง แล้วตรวจว่าเครื่องที่เลือกต้องเข้าสู่ระบบใหม่ และอีกเครื่องยังใช้งานได้
- เปิดหน้าบัญชีบนโทรศัพท์ เลือกอุปกรณ์ ย้อนกลับไปยังรายการ แล้วตรวจหน้าข้อมูลติดต่อและอีเมล
- เปิดระบบจากไอคอนและจากเว็บบนเครื่องจริง ตรวจพื้นที่ขอบจอ แป้นพิมพ์ ปุ่มย้อนกลับ และการแสดงผลเมื่อหมุนหน้าจอ
- สร้างรุ่นร่างเปล่าแล้วลบ ทดลองลบรุ่นที่เปิดรับสมัคร และตรวจว่าประวัติรุ่นที่เคยใช้งานยังอยู่
