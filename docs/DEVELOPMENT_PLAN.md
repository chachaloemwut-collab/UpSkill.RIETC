## รายละเอียดใบงาน

รายละเอียดเต็มของแต่ละใบงาน (ขอบเขต ขั้นตอน ตารางสถานะ/ปุ่ม เกณฑ์ตรวจรับ) อยู่ในแผนต้นฉบับ สรุปจุดที่ต้องทำ:

### L01 · สถานะเดียวจากฝั่งเซิร์ฟเวอร์
- ตัวประกอบสถานะเดียว (ชนิดสถานะ + รหัสเหตุผล, ปุ่มหลักและปลายทาง, คลิปที่รับรอง/ทั้งหมด, แบบทดสอบที่ส่ง/ทั้งหมด, เกณฑ์และคะแนนตามกฎหลักสูตร, เวลาล่าสุด, สถานะเอกสาร) ใช้ร่วมกันใน `/`, `/my-courses`, `/courses/[slug]`, หน้าบทเรียน เริ่มที่ `learnerOverview`, `getCourseForViewer`, `Dashboard.tsx`, `packages/core/src/completion.ts`
- ลำดับปุ่ม: รออนุมัติ/รอเปิด/ระงับ → แบบก่อนเรียน → คำถามระหว่างคลิป/ท้ายคลิปที่ค้าง → เรียนต่อ/เริ่มเรียน → สอบท้ายหลักสูตร → เลือกแบบทดสอบทำใหม่ → รับ/ดูวุฒิบัตร
- สืบกรณี “0/10 คลิปแต่ขึ้นว่าเรียนจบ” แบบอ่านอย่างเดียว ห้ามแก้ผลหรือเพิกถอนอัตโนมัติ

### U01 · บัญชีผู้ใช้
- `/me` แบ่งหมวด: ข้อมูลผู้เรียน · การเข้าสู่ระบบ · ชื่อบนวุฒิบัตร · การแจ้งเตือน · ข้อมูลและความเป็นส่วนตัว (API token อยู่ใน “การเชื่อมต่อสำหรับผู้ใช้งานขั้นสูง”) เปิดแต่ละหมวดด้วยลิงก์ได้
- ทำทะเบียนฟังก์ชันจาก UI + route `/api/auth`, `/api/user`, `/api/admin/users` พร้อมผลหลังโหลดใหม่และหลักฐานตรวจรับ

### C01 · วุฒิบัตร
- สถานะเดียวใน `/courses/[slug]/certificate` และ `/certificates`: รอยืนยันชื่อ → พร้อมออก → ออกแล้ว/กำลังสร้าง PDF → PDF พร้อม (+ สร้างไฟล์ไม่สำเร็จ, ถูกเพิกถอน)
- ตรวจสถานะเป็นระยะระหว่างเปิดหน้า, ผู้ดูแล retry คิว PDF ได้โดยไม่ออกเอกสารใหม่/ลงนามซ้ำ/ส่งอีเมลซ้ำ

### L02 · วิดีโอและแบบทดสอบ
- สถานะบันทึกเวลา (กำลังบันทึก / บันทึกแล้ว ณ … / การเชื่อมต่อขัดข้อง / ใช้งานจากอีกแท็บ), ส่งข้อสอบซ้ำหลังเน็ตหลุดไม่สร้าง attempt เกิน, ทดสอบบน Safari iPhone และ Chrome Android จริง

### A01 · ค้นหาถึงสมัคร
- คำไทยสำหรับตัวกรอง, สรุปกติกา/เกณฑ์ผ่านก่อนคำอธิบายยาว, ส่งปลายทางภายในผ่านหน้าล็อกอิน/ยืนยันอีเมล/กรอกข้อมูลด้วยรายการ route ที่อนุญาต

### T01 · ผู้สอน
- แท็บชื่อไทยเต็ม (บทเรียน · แบบทดสอบ · ใบสมัคร · ผู้เรียน · ตั้งค่า), แผงตรวจความพร้อมจาก `getPublishReadiness` ที่กดไปจุดแก้ได้, preview ไม่สร้างข้อมูลจริง

### T02 · ตั้งค่าหลักสูตร
- ทะเบียนฟิลด์ (ค่าเริ่มต้น · ช่วงที่รับ · เงื่อนไขที่มีผล · บทบาท · ผลต่อผู้เรียนเดิม · วิธีตรวจรับ), เมนูตามกลุ่ม + “ภาพรวมกติกาที่ผู้เรียนจะเห็น”, บันทึกแยกกลุ่ม

### R01 · รายงาน
- นิยามยอดชัดเจน (ลงทะเบียน/เรียนจบ/ออกวุฒิบัตร ซ้อนกันได้), server pagination, CSV ใช้ตัวกรองเดียวกับหน้า, ลำดับเหตุการณ์ของผู้เรียนในหน้ารายละเอียด

### O01 · หลักฐานก่อนส่งมอบ
- Safari iPhone, Chrome Android, iPad, Desktop Chrome, LINE · health ของ web และ worker · อีเมลกับกล่องทดสอบ · คิว PDF · การกู้ข้อมูลในสภาพแวดล้อมแยก

## ต้องให้เจ้าของระบบตัดสินใจ

1. ผู้เรียนเดิมเรียนต่อได้หรือไม่หลังหลักสูตรเข้าคลัง
2. วิธีดำเนินการกับเอกสารทดสอบเดิม
3. ถ้อยคำบนหน้าวุฒิบัตร (เช่น การเทียบโอน) ที่อนุมัติให้ใช้
4. ช่วงเวลาที่แก้หลักสูตรซึ่งมีผู้เรียนค้างได้
