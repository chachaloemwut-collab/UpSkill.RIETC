# เลขประจำตัวประชาชนในระบบสมาชิก UpskillReskill.RIETC

| กลุ่ม | เมื่อเริ่มใช้รุ่นนี้ | เมื่อต้องลงทะเบียนอบรม |
|---|---|---|
| สมาชิกเดิมที่ยังไม่มีข้อมูลผู้เรียน | เข้าบัญชีเดิมได้ ไปที่ ตั้งค่าบัญชี → ข้อมูลผู้เรียน เพื่อกรอกภายหลัง | กรอกข้อมูลและยอมรับประกาศความเป็นส่วนตัวก่อนลงทะเบียนตามกติกาเดิม |
| สมาชิกเดิมที่มีข้อมูลครบ | ใช้ข้อมูลเดิมและแสดงเลขท้ายสี่หลัก | ใช้ข้อมูลเดิมกับใบสมัครและประวัติการเรียน |
| สมัครใหม่ด้วยอีเมล | ตรวจข้อมูลผู้เรียน เลขบัตร และความยินยอมก่อนสร้างบัญชี | ยืนยันอีเมลตามขั้นตอนเดิม |
| สมัครใหม่ด้วย Google | ยืนยันบัญชี Google แล้วกรอกแบบสมาชิกภายใน 30 นาที หากหมดเวลาให้ยืนยัน Google ใหม่ ระบบสร้างบัญชี โปรไฟล์ และการเชื่อม Google พร้อมกันเมื่อข้อมูลผ่าน | ใช้บัญชีที่สมัครสำเร็จ |
| บัญชีเจ้าของระบบที่ใช้กู้บริการ | ใช้ขั้นตอนดูแลระบบเดิม | แยกจากการสมัครสมาชิกบุคคลทั่วไป |

ผู้ดูแลใช้ จัดการสมาชิก → ข้อมูลเลขประจำตัวประชาชน เพื่อเลือกรายชื่อที่ยังขาดข้อมูลและประสานเจ้าของบัญชีให้กรอกเอง ตัวกรองใช้กับการแบ่งหน้าและการส่งออกรายชื่อ ไม่ต้องส่งเลขบัตรทางแชทหรืออีเมล

ระบบตรวจรูปแบบ 13 หลัก เลขตรวจสอบ และเลขซ้ำข้ามบัญชี เก็บเลขเต็มแบบเข้ารหัสและใช้ค่าดิจิทัลที่สร้างด้วยกุญแจลับสำหรับตรวจซ้ำ การผ่านกฎนี้เป็นผลตรวจข้อมูลที่ผู้สมัครกรอก การยืนยันเจ้าของบัตรกับทะเบียนราษฎรต้องใช้บริการยืนยันตัวตนที่ได้รับอนุญาตแยกต่างหาก

หากระบบแจ้งเลขซ้ำ ให้ตรวจบัญชีเดิมผ่านผู้ดูแลก่อนออกลิงก์กู้บัญชีหรือรหัสชั่วคราว เลขบัตรเพียงอย่างเดียวไม่ใช่หลักฐานอนุมัติรีเซ็ต หากพบว่าบันทึกเลขผิด ให้ประสานเจ้าหน้าที่เพื่อตรวจหลักฐานและประวัติเอกสารก่อนพิจารณาแก้รายการ

ตรวจรับรุ่นโดยทดสอบเลขผิด เลขซ้ำ ขาดความยินยอม การหมดเวลาของการสมัคร Google และการกลับมาเติมข้อมูลของสมาชิกเดิม ตรวจว่า API หน้าสมาชิกและบันทึกเหตุการณ์ไม่เผยเลขเต็ม การเปลี่ยนรุ่นใช้โครงสร้างข้อมูลเดิม จึงไม่ต้องเติมเลขย้อนหลังหรือย้ายประวัติการอบรม
